The Course課程

Lessons for Building Beautiful Websites with AI Agents用 AI agents 製作漂亮網站的課程

Start by learning the design language website makers use. Then you can give AI agents clearer instructions: who the site is for, what the page should do, what style it should feel like, and what users should click next.

先學會網站設計者常用的語言，再學怎麼對 AI agents 下清楚指令：這個網站是給誰看的、頁面要達成什麼目的、風格要像什麼、使用者下一步該點哪裡。

0

Start Here: Design Language先從這裡開始：設計語言

Before asking an AI agent to “make it beautiful,” learn the words that describe what good websites actually do.在請 AI agent「幫我美化」之前，先學會描述好網站真正做對了什麼。

Lesson 0.1第 0.1 課

Layout & Visual Hierarchy版面與視覺層級

Learn to decide what users should notice first: hero section, above the fold, grid system, whitespace, and CTA.

學會決定使用者第一眼該看到什麼：Hero Section、Above the Fold、Grid System、Whitespace、CTA。

Open details看細節

Try asking: “Make the hero section clearly show who this site is for, add one strong CTA, and use whitespace so the first screen feels calm.”

可以這樣問：「請讓第一屏清楚看出這個網站是給誰看的，加入一個明顯 CTA，並用留白讓畫面穩定、好讀。」

Lesson 0.2第 0.2 課

UX: Make the Site Easy to UseUX：讓網站真正好用

Use terms like user journey, navigation, information architecture, accessibility, responsive design, and conversion.

學會 User Journey、Navigation、Information Architecture、Accessibility、Responsive Design、Conversion。

Open details看細節

UX check: Can a busy teacher understand the page in 5 seconds, find the next button, and read it easily on a phone?

UX 檢查：忙碌的老師能不能在 5 秒內看懂這頁、找到下一步按鈕，並且在手機上舒服閱讀？

Lesson 0.3第 0.3 課

Visual Style Direction視覺風格方向

Describe the feeling precisely: warm, trustworthy, modern, institutional, editorial, friendly, clean, or premium.

精準描述網站感覺：溫暖、可信賴、現代、機構感、雜誌感、親切、乾淨、高級感。

Open details看細節

Better than “beautiful”: “Warm and trustworthy, like an education nonprofit. Not like a cram school, not too playful.”

不要只說「漂亮」：「要溫暖、可信賴，像教育公益組織；不要像補習班，也不要太幼稚。」

Lesson 0.4第 0.4 課

Content Design內容設計

Shape headlines, subheadlines, microcopy, section flow, scannability, and calls to action.

安排 Headline、Subheadline、Microcopy、Section Flow、Scannability，以及行動呼籲。

Open details看細節

Useful section flow: who we are, what problem we solve, what we offer, proof or examples, and how to contact us.

好用的段落順序：我們是誰、解決什麼問題、提供什麼、成果或案例、如何聯絡。

Lesson 0.5第 0.5 課

How to Instruct AI Agents如何對 AI agents 下指令

Give the agent a user, goal, style direction, section order, and constraints. Clear instructions create better websites.

告訴 agent：目標使用者、網站目的、風格方向、段落順序、限制條件。指令越清楚，網站越好。

Open details看細節

Remember: AI agents work better when you give them context, examples, constraints, and what “done” should look like.

請記得：AI agents 最需要的是背景、範例、限制條件，以及你心中「完成」的樣子。

Prompt Formula指令公式

A better way to ask an AI agent更好的 AI agent 指令寫法

Open example看範例 
Please create or improve [page / section].

Target users: [who will visit this site]
Website goal: [what you want them to do]
Style direction: [warm / professional / modern / educational]
Section flow: [hero, mission, services, examples, contact]
Please check: [mobile layout, readability, speed, consistency]
請幫我製作或修改 [頁面 / 區塊]。

目標使用者：[誰會看這個網站]
網站目標：[希望他做什麼]
風格方向：[溫暖 / 專業 / 現代 / 教育感]
內容順序：[第一屏、使命、服務、案例、聯絡]
請注意：[手機版、可讀性、速度、整體一致]

Classroom example: “Please redesign my English Club homepage for Grade 4 students and parents. The goal is for parents to understand the weekly lesson and for students to click this week’s practice. Make it friendly, clean, and bilingual. Check the mobile layout.”

課堂範例：「請重新設計我的四年級 English Club 首頁，目標使用者是學生和家長。目標是讓家長了解本週課程，並讓學生點選本週練習。風格要親切、乾淨、雙語，請檢查手機版。」

Useful Vocabulary常用術語

Words website designers use網站設計者常說的話

Use these words when you talk to AI agents. They make your instructions more specific.跟 AI agents 溝通時可以使用這些詞，指令會更精準。

Hero SectionThe first major section users see.使用者第一眼看到的首頁大區塊。

Ask the agent to make this section answer: What is this site? Who is it for? What should I click next?

請 agent 讓第一屏回答三件事：這是什麼網站？給誰看？下一步要點哪裡？

CTAThe button or link you want users to click.希望使用者點擊的主要按鈕或連結。

Examples: Start Lesson 1, Contact Luke, Download Worksheet, View This Week’s Practice.

例子：開始第一課、聯絡 Luke、下載學習單、查看本週練習。

Above the FoldWhat appears before users scroll.不用往下滑就能看到的第一屏內容。

For teaching sites, put the main identity, purpose, and first action here.

教學網站第一屏應該放：網站身份、用途，以及第一個行動按鈕。

Responsive DesignLayouts that work on phones, tablets, and computers.手機、平板、電腦都好看的響應式設計。

Always ask the agent to check mobile layout, line breaks, buttons, and whether text overflows.

請 agent 一定檢查手機版、換行、按鈕大小，以及文字是否超出畫面。

Information ArchitectureHow site content is grouped and organized.網站內容如何分類與安排。

Good IA helps users know where to go: Lessons, Resources, About, Contact.

好的資訊架構讓使用者知道去哪裡：課程、資源、關於、聯絡。

ScannabilityHow quickly users can skim and understand a page.使用者是否能快速掃讀並理解頁面。

Use short headings, cards, bullets, clear labels, and enough spacing between ideas.

使用短標題、卡片、重點條列、清楚標籤，並讓不同概念之間有足夠間距。

TypographyThe system of fonts, sizes, weights, and spacing.字體、字級、粗細、間距的排版系統。

Ask for clear heading levels, readable body text, and no tiny text on mobile.

請 agent 做出清楚的標題層級、好讀的內文，手機版不要有太小的字。

Design SystemReusable rules for colors, buttons, spacing, and components.顏色、按鈕、間距、元件的共用規則。

This keeps every page consistent, especially when a site grows from 1 page to 20 pages.

當網站從 1 頁變成 20 頁時，設計系統能讓每一頁維持一致。
